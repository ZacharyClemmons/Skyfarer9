# Roadmap

This is the historical backlog. The current progress and next-session checklist live
in the repository-root [ROADMAP.md](../ROADMAP.md); several items below are already implemented.

## Known gaps / next up
- Balance pass: scientist accident rate, needs decay, reactor/TEG numbers, director pacing.
- AI: longer multi-step plans for cargo deliveries, surgery, more traitor objectives, heads
  giving direct orders to named crew, NPCs noticing lies (contradicting evidence).
- Construction: pipe/cable laying UI, building doors/machines, deconstructing machines.
- Liquids (puddles that spread), more chemistry, a proper surgery system, diseases with symptoms tree.
- Ghost/observer mode, save/load. The round ends when the evacuation crawler reaches the base.
  Could still use: traitor "escape alone" / hijack objectives.
- Art: in-hand sprites, more hair/clothing, animated machines, posters, more decals.
- Multiplayer (2-4 players): the sim is authority-agnostic (everything goes through Interact),
  so the plan is a host-authoritative model replicating Interact calls + entity state.
- Proper export: install export templates and add an export preset.
